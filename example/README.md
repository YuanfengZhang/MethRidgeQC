# chr22 test data

These files support MethRidgeQC end-to-end tests and CLI/Python examples. They contain chr22 only and do not establish genome-wide performance. Extraction preserves the original row order, all columns and their types, coordinates, counts, and beta values.

## Files and sources

- `BS1_D6_1.parquet.lz4`: cytosine counts used as QC input, from the BS1 assay on the 1st technical replicate of the D6 sample.
- `D6_reference.parquet.lz4`: D6 methylation reference values used as evaluation truth. All source annotations are retained.
- `GRCh38_chr22.fa`: the complete chr22 sequence from`Homo_sapiens.GRCh38.dna_sm.primary_assembly.fa` (RefSeq GRCh38.p14 version), with soft-mask, case preserved. The sequence is 50,818,468 bp long and supplies CpG context and strand assignments.
- `GRCh38_chr22.fa.fai`: the index generated by samtools faidx. Its five columns give the sequence name, sequence length, byte offset of the first base, bases per line, and bytes per line.

## Formats and units

The Parquet files use internal LZ4 compression. Read them directly with Polars or PyArrow; no external decompression is needed.

All records have `chrom` set to chr22. Coordinates follow GRCh38 and use zero-based, half-open intervals `[start, end)`. Each single-base record has end=start+1. The `m/u` columns hold methylated/unmethylated counts, with depth=m+u. Beta values are percentages from 0 to 100; use `--truth-scale percent` when evaluating against the reference table.

The reference table uses +/− for `strand` and records sequence context in `type`. Evaluation matches only valid CG/CpG reference records. Other Boolean, numeric, and Enum columns are source annotations; they are not used as QC training truth.

## Validation scope

Both tables were checked against their source schemas. Content samples were fixed before QC: the first, middle, and last rows after chr22 filtering. Every column in each sampled row matched the corresponding source row. Format checks cover all bundled files; the content comparison covers these samples, not every source row.

The zero-based sample row indices are:

- Counts: `0 / 572459 / 1144918`.
- Reference truth: `0 / 345432 / 690863`.

Tests also check count formulas, fixed content samples, model saving and loading on the complete chr22 input, and evaluation against reference truth. Small synthetic fixtures cover empty input, invalid counts, missing truth, and other boundary cases.

FASTA tests compare 100 bp at each position `0 / 25409234 / 50818368` between the concatenated FASTA sequence and indexed access through `.fai`. These checks test index offsets; they do not recheck the entire source genome base by base.
